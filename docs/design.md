# 양동이 디자인 / 프론트엔드 인계

## 방향

일을 관리하는 대시보드보다 곁에 있는 작은 친구를 지향합니다. 따뜻한 아이보리 배경, 차분한 세이지 액션, 살구색 양동이 캐릭터를 사용합니다. 집중을 이탈해도 비난하지 않고 복귀를 제안합니다.

- 바탕 `#F7F8F3`, 사이드바 `#EFF1E8`, 카드 `#FFFFFF`
- 주요 액션 `#76855D`, 본문 `#393A33`, 보조 본문 `#828579`
- 캐릭터 `#FFD5A3`, 윤곽 `#715747`, 볼 `#EDA184`
- 카드 반경 18px, 버튼 10px, 카드 안쪽 간격 20~22px
- 기본 창 1160×820, 최소 1040×760. 페이지는 스크롤로 작은 창에 대응
- Windows 글꼴 Malgun Gothic, macOS 미리보기 Apple SD Gothic Neo
- 캐릭터는 QPainter 벡터 도형. 별도 이미지나 폰트 다운로드 불필요

## 구조

- `state.py`: UI 상태, 집중 세션, 예시 이벤트, 메시지 시그널
- `art.py`: 해상도 독립 캐릭터
- `ui.py`: 패널 4개, 투명 펫 창, 트레이, QSettings
- `theme.py`: 공통 Qt 스타일
- `__main__.py`: 애플리케이션 진입점

## 가벼운 환경 인식 연결 제안 (미구현)

현재 프론트엔드는 시스템 활동을 감지하지 않습니다. 다음 백엔드 연결 시 화면 전체를 반복 캡처하지 않는 것이 기본 원칙입니다.

1. Windows 포그라운드 전환 이벤트를 구독해 앱 식별자와 전환 시각만 받습니다. 이벤트 훅 연결이 어려운 환경에서만 느린 주기의 폴링을 대안으로 사용합니다.
2. 앱 체류 시간은 타임스탬프로 계산하고 유휴 상태, 절전, 잠금 시간을 제외합니다. 브라우저 프로세스만으로 유튜브 방문을 단정하지 않습니다. 제목·선택적 브라우저 연동 등 별도 신호가 필요합니다.
3. 음악은 OS 미디어 세션의 재생 상태를 사용합니다. 장르는 보통 메타데이터만으로 확정할 수 없으므로 장르 정보가 없으면 추측하는 문장을 만들지 않습니다.
4. 중복 이벤트를 합치고 의미 있는 상태 변화나 시간 임계치에서만 모델을 호출합니다. 조용히 모드는 생성 전 단계에서 차단합니다. 쿨다운과 입력 길이 상한을 둡니다.
5. 추론은 UI 스레드 밖의 작업자/프로세스에서 수행합니다. 취소, 타임아웃, 실패 상태를 함께 구현하고 Qt의 queued signal로 결과를 전달합니다. 기존 `CompanionState.message`가 말풍선과 대화를 갱신합니다.
6. OCR이나 스크린샷이 꼭 필요한 기능은 별도의 사용자 설정으로 추가하고, 기본 경로에서 제외합니다.

UI는 상시 프레임 루프가 없습니다. 펫은 Qt paint 이벤트에서만 다시 그립니다. 집중 타이머만 활성 세션 동안 초당 1회 동작하며 정지·완료 시 멈춥니다. 말풍선에는 단발성 숨김 타이머를 사용합니다. 메시지 위젯은 100개까지만 유지합니다. 실제 CPU/RAM 수치는 측정하지 않았으며 절감률을 주장하지 않습니다.

## 수동 QA 체크리스트

- Windows 10/11에서 실행 후 다른 앱 위 펫 표시 및 설정으로 해제
- 드래그 이동, 두 번 클릭 복원, 우클릭 및 트레이 종료
- 100%/150%/200% 배율에서 글자 및 캐릭터 잘림 확인
- 보조 모니터 이동 및 제거 후 재실행 위치 확인
- 패널 최소화/닫기 중 집중 타이머 지속 확인
- 음소거, 크기, 위치, 항상 위 설정 재실행 유지 확인
- LLM 미연결 및 데모 정보 표시 확인
